From download to live site

1. Download Pick a design and a theme above. The zip has index.html and a README written for that template.
2. Edit Open index.html in a text editor. Follow the HOW TO EDIT comment and replace every data-field value.
3. Theme Switch themes by changing data-theme on the <html> tag, or edit the color variables at the top of the stylesheet.
4. Publish Upload the folder to GitHub Pages, Netlify, or Cloudflare Pages. No build step.
Sample names and projects are fictional. Every zip has the gallery bar removed. Download all (default themes)
