Projects

Study Buddy

Fall 2025 · team of 3 · React, Node, Postgres

A scheduler that finds a time when a study group can actually meet, using everyone’s class timetable instead of a poll nobody answers.

What I did

Designed the data model and wrote the scheduling algorithm. Set up the deployment and the database backups after we lost a week of data once.

What I learned

The hard part was not the algorithm. It was importing timetables from four different formats. I now start with the messy input, not the clever core.
